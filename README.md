# snowball-parsing-app (Приложение для сбора данных методом «снежного кома» с использованием языковых моделей)
## Краткое описание
*Назначение*: Приложение предоставляет графический интерфейс для сбора текстовых данных из социального медиа (например ВКонтакте) методом «снежного кома» – от заданных исследователем первичных публикаций к связанному с ними контенту. Отбор релевантного контента на каждом шаге расширения производится с помощью языковых моделей, которые вычисляют семантическую близость текстов.

*Проблема*: Метод «снежного кома» (snowball sampling) является устоявшимся подходом в исследованиях социальных медиа. Однако существующие реализации этого метода представляют собой Python-скрипты, требующие навыков программирования, и остаются недоступными для исследователей. 
При этом графические инструменты сбора данных из социальных медиа, как правило, не реализуют логику «снежного кома». Они лишь позволяют собирать данные по ключевым словам или через API, но не поддерживают итеративное расширение выборки через неявные связи.
Отдельной проблемой является точность отбора при расширении выборки. Наивный «снежный ком» приводит к накоплению нерелевантного контента. Языковые модели позволяют решить эту проблему: вместо механического перехода по связям можно сравнивать семантическую близость текстов и включать в выборку только те элементы, которые действительно соответствуют исходной теме.

## Существующие решения для сбора данных VK
1.	Скрипты для «снежного кома» (например parservk для ВКонтакте) – требуют установки Python, запуска из командной строки, не рассчитаны на работу с языковыми моделями.
2.	Графические инструменты сбора данных
2.1.	4CAT – онлайн платформа, ориентированна на англоязычные социальные медиа, не поддерживает стратегию «снежного кома»
2.2.	Communalytic – онлайн платформа с подпиской, ориентированна на англоязычные социальные медиа, не поддерживает стратегию «снежного кома»

Ни один из существующих инструментов не сочетает: (а) графический интерфейс, доступный исследователю без навыков программирования; (б) логику «снежного кома» как итеративного расширения выборки через связи; (в) использование языковых моделей для семантической фильтрации релевантного контента; (г) поддержку русскоязычных социальных медиа (например ВКонтакте).

## Цель
Создание десктопного приложения для сбора массивов текстовых данных из ВКонтакте методом «снежного кома» с семантической фильтрацией на основе языковых моделей, с платформо-независимым ядром, допускающим расширение на другие платформы в будущем.

## План
-	Анализ потребностей исследователей в сборе данных: изучение существующих практик применения «снежного кома», выявление типовых сценариев (сбор по сообществу, по хештегу, по автору) и требований к экспорту.
-	Проектирование модели данных «снежного кома»: определение структуры исходных записей, правил расширения, критериев остановки и формата хранения связей между элементами.
-	Создание платформо-независимого ядра сбора: реализация итеративного обхода связей с абстракцией от конкретной платформы.
-	Реализация адаптера VK: создание модуля для работы с VK API, с обработкой лимитов и задержек.
-	Интеграция языковых моделей для семантической фильтрации: подключение моделей для вычисления семантической близости текстов и настройка порога релевантности в интерфейсе.

## Команда
-	Фронтенд-разработчик десктопного приложения (можно веб-интерфейс)
-	Бэкенд-разработчик десктопного приложения

## Ожидаемый результат
Десктопное приложение с установщиком, которое имеет ряд функций:
-	Окно ввода исходных записей: пользователь указывает начальные сообщества, посты или пользователей VK.
-	Окно подключения к VK API: ввод токена доступа (сервисный ключ или пользовательский токен).
-	Окно настройки семантической фильтрации: выбор языковой модели для вычисления близости текстов, настройка порога релевантности, выбор стратегии сравнения.
-	Окно извлечения данных, включая итеративное расширение выборки, фильтрацию, учёт лимитов API, критерии остановки, возможность паузы и возобновления сбора.
-	Окно экспорта для выгрузки CSV-файла с собранными текстами, метаданными (источник, глубина, оценка близости) и связями между элементами.
