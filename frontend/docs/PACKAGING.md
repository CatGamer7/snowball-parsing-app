# Упаковка в установщик (SNO-6)

## Как собрать

```
npm run build:win
```

Результат: `dist/snowball-frontend-<версия>-setup.exe`.
Первая сборка дольше: electron-builder скачивает инструменты.

## Чем собираем

**electron-builder**: берёт собранное приложение из `out/`, добавляет Electron и упаковывает в установщик NSIS (классический мастер установки Windows).
Конфигурация лежит в `electron-builder.yml`.

## Что изменено относительно шаблона

| Настройка | Было | Стало | Зачем |
|---|---|---|---|
| `appId` | `com.electron.app` | `ru.tpu.snowball` | уникальный идентификатор для Windows |
| `productName` | `frontend` | `Snowball` | название в установщике, меню «Пуск», на ярлыке |
| `win.executableName` | `frontend` | `snowball` | имя `.exe` после установки |
| `nsis.oneClick` | `true` | `false` | мастер с кнопками вместо молчаливой установки |
| `nsis.allowToChangeInstallationDirectory` | — | `true` | пользователь выбирает папку установки |
| `mac.extendInfo` | камера, микрофон, папки | удалено | приложению эти разрешения не нужны |
| `linux.target` | AppImage, snap, deb | AppImage | один универсальный формат |
| `publish` | заглушка `example.com` | удалено | сервера обновлений нет |

Идентификатор в `src/main/index.ts` (`setAppUserModelId`) совпадает с `appId`. Иначе Windows покажет на панели задач два значка вместо одного.

## Куда устанавливается

| Режим | Папка |
|---|---|
| Только для меня | `%LOCALAPPDATA%\Programs\Snowball` |
| Для всех пользователей | `C:\Program Files\Snowball` (нужны права администратора) |

## Известные особенности

- **«Windows защитила ваш компьютер».** Установщик без цифровой подписи, поэтому Windows его предупреждает. Нажать «Подробнее» → «Выполнить в любом случае». Подпись платная, для учебного проекта не нужна.
- **Значок Electron.** Своей иконки пока нет. Когда появится, положить `icon.ico` в папку `build/`.
- **Зависание на «Готово» с галочкой «Запустить Snowball».** Установка к этому моменту уже завершена. Снять галочку или закрыть установщик через Диспетчер задач и запустить программу ярлыком.

## Дальше

Когда будет готов Python-бэкенд, его тоже нужно положить в установщик (через `extraResources` в `electron-builder.yml`). Это отдельная задача.
