# Snowball — фронтенд

Десктопное приложение для сбора текстов из ВКонтакте методом «снежного кома».

## Стек и почему он

| Что | Выбор | Обоснование |
|---|---|---|
| Десктопная оболочка | Electron | Интерфейс пишется на веб-технологиях, работает на Windows/Linux/macOS, умеет запускать Python-бэкенд как отдельный процесс |
| Интерфейс | React + TypeScript | Самый распространённый стек, типы ловят ошибки до запуска |
| Сборка | electron-vite | Быстрый dev-сервер с обновлением на лету, main/preload/renderer в одном конфиге |
| Линтер | ESLint + Prettier | Единый стиль кода в команде |
| Установщик | electron-builder | Собирает .exe для Windows |

Альтернативы: Tauri (меньше размер, но требует Rust), чисто веб-интерфейс (проще, но не десктоп).

## Требования

Node.js 20+

## Команды

| Команда | Что делает |
|---|---|
| `npm install` | установить зависимости (один раз после клонирования) |
| `npm run dev` | запустить в режиме разработки |
| `npm run lint` | проверить код линтером |
| `npm run format` | отформатировать код |
| `npm run build` | проверить типы и собрать приложение в `out/` |
| `npm run start` | запустить собранную версию |
| `npm run build:win` | собрать установщик для Windows |

## Структура

```
src/
├── main/       главный процесс Electron: окно, работа с системой
├── preload/    мост между main и интерфейсом
└── renderer/   интерфейс на React
```

## Известные проблемы

**Белое окно и `ERR_CONNECTION_REFUSED` при `npm run dev` на Windows.** Dev-сервер и Electron по-разному понимают `localhost`. Уже исправлено: в `electron.vite.config.ts` указан `server.host: '127.0.0.1'`.
