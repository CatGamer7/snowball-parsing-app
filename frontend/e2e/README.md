# E2E-тесты (SNO-17)

Playwright запускает собранное Electron-приложение и подменяет Python-бэкенд заглушкой,
поэтому бэкенд и токен VK для тестов не нужны.

## Запуск

Из папки `frontend`:

| Команда                      | Что делает                                         |
| ---------------------------- | -------------------------------------------------- |
| `npm install`                | установить зависимости (один раз)                  |
| `npm run test:e2e`           | собрать приложение в `out/` и прогнать тесты       |
| `npx playwright test`        | прогнать тесты без пересборки (если `out/` свежий) |
| `npx playwright show-report` | открыть HTML-отчёт последнего прогона              |

## Что лежит

```
e2e/
├── smoke.spec.ts            приложение запускается, нет ошибок в консоли, заглушка бэкенда отвечает
├── collection-flow.spec.ts  токен → начальные записи → метод сравнения → запуск → mock-результат
└── helpers/
    ├── app.ts               запуск приложения с заглушкой, сбор ошибок консоли
    └── mock-backend.ts      ответы заглушки и журнал запросов интерфейса
```

Заглушка перехватывает запросы к `http://127.0.0.1:<любой порт>`:
`GET /health`, `POST /vk/validate`, `GET /collection/models`, `POST /collection/start`,
`GET /collection/<id>`. Ответы соответствуют контракту `openapi.yaml` 0.2.0 (SNO-9);
при его изменении поправить только `helpers/mock-backend.ts`. Точки результатов в контракте
пока нет, поэтому `GET /collection/<id>` — условный путь.

## data-testid для экранов

Сценарий ищет элементы по `data-testid`. Пока на экране нет `token-input`, сценарий
пропускается (`skipped`). Когда экраны появятся с этими id, он начнёт выполняться сам.

| Экран            | data-testid                                                                                   |
| ---------------- | --------------------------------------------------------------------------------------------- |
| Токен            | `token-input`, `token-check`, `token-error`, `token-next`                                     |
| Начальные записи | `seed-input`, `seed-add`, `seed-item` (каждая запись), `seeds-next`                           |
| Метод сравнения  | `model-select`, `labels-input` (типы сущностей GLiNER), `threshold-input`, `collection-start` |
| Результат        | `result-item` (каждая собранная запись)                                                       |

## Известные проблемы

**CSP блокирует запросы к бэкенду.** В `src/renderer/index.html` стоит
`default-src 'self'`, поэтому окно не может обратиться к `http://127.0.0.1:8000`
(в консоли: «Refused to connect … violates the document's Content Security Policy»).
Нужно добавить, например, `connect-src 'self' http://127.0.0.1:*`.
Тест «интерфейс получает ответы бэкенда-заглушки» помечен `test.fail` — после исправления
он покажет «unexpectedly passed», тогда пометку убрать.
